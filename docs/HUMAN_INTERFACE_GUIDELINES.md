# BDO Music Composer 界面设计规范（HIG）

这份规范是本项目界面设计的唯一入口。以最近一次明确的用户反馈修订规范。历史截图和审计用于核对当时的实现，新设计从本页出发。

## 视觉方向

- **基础界面。** 菜单、设置、编辑控件和欢迎页标题使用当前语言的圆体。首页「开始创作」使用同语言的手写体。单色图标、一致留白和清楚的操作层级沿用 OpenAI 界面指南。编排和卷帘占据主要空间，属性和工具贴近当前对象。主窗口、设置和反馈共用哑光石墨灰。用少量明度变化区分工作区、侧栏和输入控件。 [OpenAI 界面指南](https://developers.openai.com/plugins/concepts/ui-guidelines) · [应用界面层级](https://developers.openai.com/blog/designing-delightful-frontends-with-gpt-5-4#apps)
- **游戏风格。** 首页插画和乐器图形承担《黑色沙漠》的视觉辨识度。编排和卷帘用轨道色、节拍刻度、选区短标记和电平表表达音乐状态。琥珀色用于首要操作、键盘焦点和播放位置。低对比玻璃质感限于当前工具的选中状态，常用操作区域保持平整。
- **形状。** 普通控件用 6 DIP 圆角，小指标用 4 DIP。控件组外角等于内角加内边距。非最大化工作区用 12 DIP 外角和 4 DIP 内缩，内页为 8 DIP。设置和反馈用 12 DIP 外角，贴边子区用 11 DIP。拖选框、时间尺和音符保持清楚的网格边界。
- **标题栏。** 主页和音乐库用实心图标标出当前页面。左上角的黑白 Logo 打开关于面板，反馈保留独立入口和未读标记。
- **用排版划分区域。** 先对齐，再用组内间距、组间留白和底色分区。界面区块按需加单边分隔线。输入边界、编辑选区和拖动手柄按操作需要显示。系统窗口轮廓由平台处理，未读点和单选指示使用各自的形状。
- **颜色对应任务。** 中性色承担导航和次要控件。一个任务表面以一个首要动作引导下一步。主动作、选中、键盘焦点、播放和错误各有不同的辨识方式。琥珀色是现有主题中的强调色，新配色以状态可辨为验收条件。轨道色跨时间轴、卷帘与属性面板保持一致。

| 状态 | 可观察的信号 |
|---|---|
| 悬停、按下 | 当前目标底色变化，原位置和尺寸稳定。 |
| 选中 | 主页和音乐库的实心图标在焦点移入内容区后仍可辨。循环开启时箭头中间出现标记，AUTO 用空心与实心点区分。轨道在自身色条上加一小段浅色标记，Clip 和音符用细轮廓与短手柄保留原有配色。多选给出数量或范围。 |
| 键盘焦点 | 标题栏按钮点亮图标，文字输入保留插入光标。页面工具用低对比的圆角轮廓，表单和列表使用对应的焦点样式。焦点和已开启状态同时可辨。 |
| 播放、编辑位置 | 播放头持续移动，编辑位置固定并使用不同的标记。 |
| 需要修复、暂不可用 | 错误标到对应对象，给出原因和修复动作。禁用控件在必要时说明何时能使用。 |
| 未读进展 | 标题栏显示圆点，工具提示和可访问说明提供数量，列表用未读标记与字重补充。 |

## 布局与操作

| 区域 | 规则 | 试用时应观察到 |
|---|---|---|
| 首次启动 | 欢迎内容嵌入主页。左侧介绍曲谱工作流和匿名统计，自动显示系统时区。右侧沿用主页插画，底栏固定两个同等醒目的分享选项。 | 选择后直接进入项目页。系统时区只在本机显示，按回车不会代替用户同意。 |
| 首页 | 左栏依序排列标题、创作入口和曲谱库。三个创作入口单行等宽，只有「新建项目」用琥珀色。搜索与刷新共用一行，类别紧贴列表，选中项采用平整的中性底色。右侧为插画区，图像边缘淡入工作区底色。 | 启动或返回主页时先聚焦标题栏 Home。最小窗口保留全部入口，长项目名和空列表可读。 |
| 标题栏 | Logo 居中，主页、项目、音乐库三个导航入口等宽，使用相同的间隔。带文字导航按最宽的本地化入口确定宽度。编排页的独立图标居中，项目图标与下拉箭头作为一组对齐。播放和 BPM 同组居中。导出、反馈、更多靠右，用细竖线隔开窗口控制。组间留白可拖动窗口。 | 编排页的导航名称可通过悬停提示或辅助技术读取。长标题在自身区域内收缩，三位 BPM、未读点和窗口按键都可见。首次进入内嵌音乐库时先显示公益网站署名，确认后加载。同一运行期间再次点击音乐库可返回原页面。 |
| 编排 | 时间轴是最大连续区域。打开工程时直接显示编排。选择、切分、吸附和撤销就近可达，范围视图和低频全曲命令进入相应菜单。开启侧栏或窗口变窄时，卷帘、属性和 Agent 切换可缩为等宽图标，工具栏保持在可见区域内。用小节、拍和细分网格的明度层级建立方向。 | 单击 Clip 选择，双击进入卷帘。紧凑按钮仍提供工具提示及辅助技术名称。点画布空白或按 Esc 清除轨道和 Clip 选择。菜单和快捷键都可回到全曲视图。 |
| 轨道与 Clip | 轨道头保留身份、静音、独奏。Clip 的位置和宽度对齐时间，名称和音符预览分别占据清楚的区域。短 Clip 优先保留可点击范围，能修剪时显示手柄。 | 缩小时先看出曲式和轨道，放大后能看清名称、定位起止并完成修剪。 |
| 参考音频 | 编排底部提供添加或重新关联入口。载入后显示文件名和沿工程时间绘制的波形。参考轨的更多菜单和右键入口共用偏移、音量、替换与移除操作。 | 点击波形移动工程播放头。调整偏移时，波形与音频一起沿同一时间轴移动。独听按循环选区与录音的重叠范围重复播放。拒绝更换时保持当前文件和试听状态。 |
| 菜单 | 轨道和 Clip 先显示编辑入口，结构编辑、混音和属性放在对应的子菜单。删除单独放在底部。嵌入的缩放和位置控件沿用菜单项的文字与右侧留白。勾选用中性标记，禁用勾选仍保留形状。 | Clip 可在属性里改名、换色和改力度基数。卷帘空白处可在光标所指时间粘贴音符，右键音符仍可快速删除。键盘可区分当前菜单项、勾选项和禁用项。 |
| 二级菜单 | 按分组名称展开，保留父级高亮和可辨认的子菜单箭头。选项的勾选反映当前生效值。只有表单的子菜单打开时聚焦首个字段。混合菜单导航到嵌入条目时，把焦点交给其中的控件。 | 方向键可以进入子菜单。按 Esc 返回上一级，焦点回到刚展开的条目。菜单靠近屏幕边缘时仍能看全，滑块可用键盘完成调整。 |
| 下载 | 主页下载列表把文件名与状态放在两行，超长名称可从提示中查看。曲谱下载完成后可双击、按回车或点「打开曲谱」。 | ZIP 和其他文件仍可打开所在文件夹。完成与失败提示保持静音。打开不兼容的曲谱时说明支持的版本。 |
| 钢琴卷帘与力度 | 音高沿纵轴，时间沿横轴，力度泳道与音符共享时间位置。选中音符保留原色，侧边短标记提示可修剪位置。参考音频和候选音符有各自的标识。 | 在密集片段中可同时认出音高、选中范围、播放位置和力度。在选择模式下，Esc 或点空白可取消音符选区。 |
| 停靠式音符编辑 | 轨道色和名称标明编辑范围，播放、网格和编辑操作各自成组。空间收紧时保留网格分度和对齐，力度按钮用图标及工具提示。属性栏对齐乐器、音量和移调。鼓键名称过长时保留开头和省略号。 | 在同屏编排中能分辨工程撤销和音符撤销。长片段无法在最低缩放下一屏显示时，首次打开从编排播放头所在乐句或片段的第一组音符开始。选区适应命令仍可单独使用。 |
| 属性与高级操作 | 右下角的属性浮层跟随轨道、Clip 或音符选择。乐器、游戏音量和移调并排显示，音符和轨道效果按页切换。全曲力度和全局效果可从编排工具栏直接打开。 | 打开与关闭属性时刻度、音块和工具栏位置保持稳定。调整前看清对象、范围和单位。 |
| 创作 Agent | 对话内容放在内缩的阅读区，支持流式 Markdown。选区和参考音频状态贴在输入框上方。模型入口和发送分别位于输入框底部两侧，发送或停止占用同一位置。实际改谱后在对应回复内显示回执，标明动作与影响范围。 | 空白会话可用就近的建议填入草稿。开始输入后，建议让出空间。本轮请求显示发送的选区和处理阶段。可从回执跳到改动处，并用工程撤销恢复。翻阅旧回复时滚动位置保持稳定，可点「回到最新回复」。停靠和悬浮共享对话及输入草稿。 |
| Agent 模型设置 | 立绘固定在左侧。右侧用下拉框选择模型和响应方式，API 密钥与测试入口就近放置。官方地址、加密保存和清除连接收在「连接选项」。自定义接口显示 API 地址和模型 ID。底部主要操作是「应用」。 | 切换模型时立绘保持固定。可用键盘操作模型和表单，测试结果紧邻连接操作。窄窗的立绘收为短幅，表单可纵向滚动。 |
| 设置 | 主窗口中央浮出面板。Qt 工作区使用一次虚化截图，音乐库的原生网页用独立遮罩降亮。面板开合使用同一位置的短淡入淡出。 | 可以用右上角关闭键或 Esc 返回原页面，网页仍可见且操作被模态框阻挡。 |
| 反馈 | 沿用设置的浮层。左侧是收件箱，右侧写反馈、查询或读结果。状态按已提交、已查收、已回复表达，查看哪条就更新哪条的未读状态。发送前可检查选中的诊断附件。 | 能区分提交成功和维护者回复。可以用查询码回看结果，切换读写时能找回当前草稿。 |

导出、优化和扒谱建议都要先说明会影响哪些内容。可以修复的问题指到对应轨道或音符，候选改动先给预览，再由用户确认。试听、保存和导出读取同一份当前编辑模型。已经同步的 Clip 编辑与等待应用的整轨草稿，要在界面上让用户看得出来。

## 设计学与认知心理

信息架构决定动作在哪里，视觉设计决定先看到什么，人因工程关心能否舒服地点到。认知与交互设计关心用户能否预判后果、看懂结果和纠正误操作。

| 原则 | 对应设计 |
|---|---|
| 视觉层级 | 用字号、明度和留白给视线定顺序。首页先看入口，编排先看谱面，只有当前首要动作需要明显强调。 [OpenAI 界面指南](https://developers.openai.com/plugins/concepts/ui-guidelines) |
| 格式塔的邻近与相似 | 相邻且样式一致的元素容易被视为一组。播放控制彼此靠近，和项目操作留出间距。 [NN/g 邻近原则](https://www.nngroup.com/articles/gestalt-proximity/) |
| 识别优先与渐进披露 | 常用命令保持可见，低频参数放到有名称的菜单或可展开区域。快捷键、当前编辑模式和参数作用范围在现场可以确认。 [NN/g 可用性启发式](https://www.nngroup.com/articles/ten-usability-heuristics/) |
| 费茨定律 | 固定高频动作的位置，让点击区域大于图标。图标可以是 16 DIP，实际点击目标按常用按钮 32 DIP 设计。短 Clip 也要留出明确的移动目标。 [华盛顿大学交互教材](https://faculty.washington.edu/ajko/books/user-interface-software-and-technology/pointing) |
| 操作线索 | 通过可见标记提示哪里能操作。Clip 边缘的手柄提示修剪，分隔条提示调整面板高度。单击选择与双击编辑各有可辨认的结果。 [Don Norman 的操作线索](https://jnd.org/signifiers-not-affordances/) |
| 状态可见与可逆 | 编辑后立刻看到变化，长操作显示进度或失败原因。能撤销的编辑直接给撤销，导出阻断给对象和修复方向。 [NN/g 可用性启发式](https://www.nngroup.com/articles/ten-usability-heuristics/) |

## 尺寸、可访问性与验收

- 单位使用 DIP。标题栏 44，编排栏 48，常用按钮 32，首页入口 44，功能图标 16。组内间距优先用 4 或 8，独立工具组 12，面板内边距 16，页面区段用 24。Windows 按界面语言使用 Segoe UI、微软雅黑 UI、微软正黑 UI、Yu Gothic UI 或 Malgun Gothic。缺字由系统补齐。
- 普通有效文本目标至少 4.5:1。用来识别控件或操作状态的非文本信息目标至少 3:1。次要分隔线可更淡。状态用文字、形状或位置辅助辨认。 [W3C 文本对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [非文本对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) · [颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)
- 在 Windows 实窗和离屏检查中覆盖主窗口 1160 × 720、反馈 716 × 420、100%／125%／150% 缩放，以及简中、繁中、英文、日文和韩文。覆盖长名称、空列表、禁用菜单项、选中加焦点、窄窗口和部分收起的面板。仅图标控件有工具提示与可访问名称。
- 对照截图与控件几何确认对齐。独立图标的可见轮廓与点击区域中心允许相差 1 个物理像素，下拉按钮按图标与箭头的整体检查。普通、悬停、选中和键盘聚焦都使用同一个图标位置。检查多语言工具提示、辅助技术名称和窗口缩小后的操作范围。
- 排版先给当前对象、数值和单位留位置。空间收紧时，详情文本换行，长对象名保留可识别的开头并提供完整提示，少用的操作收进相应菜单。可见操作在窗口边缘留出容纳描边和焦点的空间。
- 页面切换立即交付键盘焦点。导航标记从切换前的实际位置出发，等标题栏完成排版后对准新入口。连续切换从当前绘制位置接续。动效集中在导航、浮窗和状态提示，播放和拖动时保留局部重绘。
- 关闭界面动效时立即结束正在播放的导航标记与提示淡入淡出。复测快速取消浮窗后重开，确认透明度、焦点与背景正确恢复。当前页和选区仍可通过它们各自的静态状态辨认。
- 用实际任务验收。先跑「导入 → 选 Clip → 改音符与力度 → 撤销 → 导出校验」，再跑「写反馈 → 查收 → 有回复 → 逐条读」。修改画布需核对可见范围索引和缓存。规范发布后，数值与状态仍按每次实现的验证结果记录。

# BDO Music Composer

[简体中文](zh-CN.md) · [English](en.md) · [日本語](ja.md) · [한국어](ko.md) · [プロジェクトホーム](../../README.md)

BDO Music Composer は Black Desert の作曲プレイヤー向けローカル・マルチトラックエディターです。MIDI の読み込み、Clip の配置、音符とベロシティの編集、ゲーム用楽譜の書き出しを一つにつなぎます。汎用 DAW ではなく、Pearl Abyss とは提携していません。

> 本ツールは制限対象コンテンツの取得や配布を行いません。外部コンテンツの出所と利用許可は利用者が確認してください。

<!-- section:status -->
## 今使える状態ですか

v1.3.6 では編集、自動保存、最適化、試聴、採譜支援、楽譜書き出しを回帰テストしています。ゲーム内の楽譜仕様が変わらなければ、この版を当面の長期安定版として保守する予定です。PC、音声機器、ゲームバージョンによる差は残ります。

<!-- section:features -->
## 主な機能

- MIDI の読み込みまたは空のプロジェクトから、マルチトラック上のクリップを配置、分割、移動、結合。
- マーカー、クリップ、グリッドの順で優先する自動スナップを使い、ピアノロールでノート、ベロシティ、リズム、奏法を編集。
- 現在の編集状態を保ったまま既存楽譜を開き、再編集して書き出し。
- ローカル採譜支援の結果を、確定前に編集可能な下書きとして確認。
- 取り消し可能な最適化、自動保存、自動書き出し検証、ローカルプロジェクト管理。

ソース版のツールバーに「創作アシスタント」を追加しました。短いスケッチの生成、
旋律への伴奏、選択したゲーム楽器への適合、強弱や音長の調整を提案します。
試聴して声部を選び、適用後も取り消せます。初版は音楽規則に基づくもので、
公開 EXE にはまだ含まれない場合があります。[実装・モデル計画](../CREATION_ASSISTANT_PLAN.md)（中国語）を参照してください。

<!-- section:requirements -->
## 導入と起動

通常は公開 Windows 版を使用してください。ソース開発には Python 3.12 と[コントリビューションガイド](../../CONTRIBUTING.md)の環境が必要です。入口は `main.py` です。

<!-- section:workflow -->
## 基本ワークフロー

1. プロジェクト作成、MIDI 読み込み、または楽譜を開きます。
2. タイムラインでクリップを配置し、ピアノロールでノートを調整します。
3. 試聴と自動検証で結果を確認します。
4. 有効な Owner ID で書き出し、ゲーム内で確認します。

<!-- section:local-assets -->
## ローカルコンテンツ

プロジェクト、設定、キャッシュ、外部コンテンツはローカルに留まります。外部コンテンツが自動的にリポジトリや公開物へ入ることはありません。

公開ページでは、近似試聴用の
`BDO-Approximate-CC0-Full-Coverage-v4-Compact.bdosamples` を別ファイルとして
提供する場合があります。アプリには内蔵されません。設定の「音源パック」からこのファイル、
または必要な権利を持つ互換パックを選択できます。内蔵汎用音源は常に利用できます。

v4 の WAV バイトは、独立した CC0 ライブラリである
[VSCO 2 Community Edition](https://github.com/sgossner/VSCO-2-CE)、
[Versilian Community Sample Library](https://github.com/sgossner/VCSL)、
[FreePats CC0 音源](https://freepats.zenvoid.org/)から選定されています。
`manifest.json` は全スロットの出典、上流相対パス、SHA-256 を記録します。
Black Desert クライアント音声は含まず、ゲーム原音や A/B 検証済み音源ではありません。
v1.2.1 の SHA-256 は
`82cea29f1316b943571663e4150b31e353da4ab9f556141ed65b6598a384db63` です。

<!-- section:invariants -->
## 正確性の境界

現在の編集状態は試聴、保存、書き出しまで維持されます。元の読み込み内容への暗黙の後退や、未対応条件での成功表示は行いません。[AGENTS.md](../../AGENTS.md)を参照してください。

<!-- section:testing -->
## 検証

保守時には完全テスト、構造検査、必要な UI・パッケージのスモークテストを実行します。[AI コンテキスト](../AI_CONTEXT.md)と[引き継ぎガイド](../AGENT_HANDOFF.md)に最低条件があります。

<!-- section:packaging -->
## 公開

公開物は依存関係、ライセンス、プライバシー、リソース、起動検査を通過する必要があります。利用者データ、キャッシュ、外部コンテンツ、秘密鍵は含めません。

<!-- section:privacy -->
## プライバシー

アカウントログイン、テレメトリー、ファイル送信はありません。楽譜には Owner ID やキャラクター情報が含まれる場合があるため、公開リポジトリへ登録しないでください。
